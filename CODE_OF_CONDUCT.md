# Code of conduct

The code of conduct of the AgenticSystemCore project applies to this repository
unchanged:
<https://github.com/andreibesleaga/agentic-system-core/blob/main/CODE_OF_CONDUCT.md>.
It says how everyone taking part is expected to behave, in issues, pull requests and
anywhere else the project is represented, and what happens when someone does not.

Report a problem through the contact page at <https://andreibesleaga.com/contact/>.
Say where it happened and link to it. Reports are read by the maintainer only and are
not published. A report about the maintainer, who is the one person enforcing the
code of conduct, can go to GitHub instead, through its own tools for reporting abuse
or content.
